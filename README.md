# Freshly
Freshly is a high-fidelity mobile application designed to bridge the gap between local artisans and community buyers. Built with a focus on sustainability, transparency, and "farm-to-table" convenience, the platform provides a seamless end-to-end marketplace experience for both consumers and independent sellers.

🌿 Vision
To empower local food systems by providing a digital marketplace where quality is grounded in community and delivered directly to the doorstep.

✨ Key Features  
For Buyers
>Discovery Feed: A curated, location-aware feed of farm-fresh goods including dairy, produce, and flowers.

>Smart Cart Management: Unified basket system that groups items by seller for clear logistics and transparency.

>Real-time Order Tracking: Interactive map-based tracking with live status updates, from "Picked at Farm" to "Delivered."

>Direct Refund & Support: Direct-to-seller communication channel for quick issue resolution and refund requests.

>Address Manager: Comprehensive location management with delivery zone verification (Green Zones).



For Sellers
>Artisan Dashboard: Centralized hub for tracking total earnings, active listings, and fulfillment metrics.

>Sales History & Trends: Detailed transaction logs and 7-day/30-day sales performance visualizations.

>Intuitive Item Listing: Streamlined multi-step form for adding new harvests with plucked dates, fresh periods, and logistics details.

>Refund Management: Robust seller-side interface for reviewing refund requests and processing reversals via original payment methods, store credit, or digital wallets.


Trust & Verification
>Same-day Image Verification using Metadata Validation
>Secure Payment Options
>Transparent Buyer-Seller Interaction
